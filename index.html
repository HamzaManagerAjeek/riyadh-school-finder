What Qurbi is (and isn't)

Both tools run on hand-curated samples, not live feeds — built to prove the idea works, with more data added over time. They're free, need no signup, and don't track you personally. In a medical emergency, always call 997 or 911 first — Qurbi is for planning, not for replacing emergency dispatch.
